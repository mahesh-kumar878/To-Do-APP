To-Do App

A simple and interactive To-Do App built using HTML, CSS, and JavaScript.

🚀 Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- ✏️ Edit tasks
- 🗑️ Delete tasks
- 🔍 Filter All, Active and Completed tasks
- 💾 Tasks saved using Local Storage
- 📱 Responsive design

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

🎯 Purpose

This project was built to practice JavaScript, DOM manipulation, and Local Storage.
